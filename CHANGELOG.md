## [0.1.0] - 2026-11-05

### Added

- Autonomous Agents — CoreAgent plans, selects tools, evaluates results and iterates without human guidance
- Apktool Wrapper — Decompiles APKs, extracts manifest, resources and Smali with one method call
- Security Analyzer — LLM examines decompiled code, permissions, web responses for OWASP issues
- Web Scanner — Crawls PHP apps and detects XSS, SQLi, insecure headers and misconfigurations
- Rich Reports — Generates console, JSON and self-contained HTML reports with severity and fixes
- Tool Registry — Extensible registry lets you register new PHP tools in seconds
- Interactive Mode — Chat with the agent to drill into specific findings or request deeper analysis
- Configurable LLMs — Works with OpenAI, Azure or any OpenAI-compatible endpoint via simple config
